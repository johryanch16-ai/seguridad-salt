# 🚀 GUÍA DE IMPLEMENTACIÓN: SUPABASE Y RENDER PARA SEGURIDAD SALT

Esta guía paso a paso te explica cómo conectar la base de datos **Supabase** para respaldar todas las cotizaciones como bitácora y cómo publicar el sitio en **Render** con un dominio gratis `https://seguridad-salt.onrender.com`.

---

## 📦 PARTE 1: BASE DE DATOS Y BITÁCORA EN SUPABASE

### Paso 1: Crear cuenta y proyecto en Supabase (Gratis)
1. Ve a [https://supabase.com/](https://supabase.com/) e inicia sesión con tu cuenta (o regístrate con GitHub / Correo).
2. Haz clic en **"New Project"**.
3. Completa los datos:
   - **Name**: `seguridad-salt`
   - **Database Password**: Genera una contraseña segura y guárdala.
   - **Region**: Selecciona la más cercana (ej: `East US - North Virginia`).
   - **Pricing Plan**: Free (Gratis $0/mes).
4. Haz clic en **"Create new project"** y espera 1 a 2 minutos a que termine de aprovisionarse.

---

### Paso 2: Crear la tabla de Bitácora (`cotizaciones`)
1. En el menú lateral izquierdo de Supabase, entra en **SQL Editor** (ícono `>_`).
2. Haz clic en **"New query"**.
3. Abre el archivo `supabase_schema.sql` que está en la carpeta de este proyecto, copia todo su contenido y pégalo en el editor de Supabase:

```sql
-- 1. Crear tabla de cotizaciones
CREATE TABLE IF NOT EXISTS public.cotizaciones (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    created_at TIMESTAMPTZ DEFAULT TIMEZONE('utc'::text, NOW()) NOT NULL,
    full_name TEXT NOT NULL,
    client_type TEXT,
    phone TEXT NOT NULL,
    email TEXT,
    service_type TEXT,
    comments TEXT,
    status TEXT DEFAULT 'Pendiente',
    notes TEXT
);

-- 2. Habilitar RLS
ALTER TABLE public.cotizaciones ENABLE ROW LEVEL SECURITY;

-- 3. Permitir que cualquier visitante del formulario inserte cotizaciones
CREATE POLICY "Permitir insercion anonima de cotizaciones"
ON public.cotizaciones
FOR INSERT
TO anon
WITH CHECK (true);

-- 4. Permitir lectura de cotizaciones (para bitacora.html y panel)
CREATE POLICY "Permitir lectura de cotizaciones"
ON public.cotizaciones
FOR SELECT
TO anon, authenticated
USING (true);

-- 5. Índices para velocidad
CREATE INDEX IF NOT EXISTS idx_cotizaciones_created_at ON public.cotizaciones (created_at DESC);
CREATE INDEX IF NOT EXISTS idx_cotizaciones_service ON public.cotizaciones (service_type);
```

4. Haz clic en el botón verde **"Run"** (o presiona `Ctrl + Enter`).
5. Verás el mensaje *"Success. No rows returned"*. ¡Tu base de datos está lista!

---

### Paso 3: Obtener tus credenciales y pegarlas en el código
1. En el menú lateral de Supabase, ve a **Project Settings** (ícono de engranaje ⚙️) > **API** (o **Data API**).
2. Copia dos valores:
   - **Project URL**: Ejemplo `https://abcdefghijklm.supabase.co`
   - **Project API Keys** > Copia la clave **`anon` / `public`** (es un texto largo que empieza con `eyJhb...`).
3. Abre en tu editor el archivo:
   👉 `js/config.js`
4. Pega tus datos en las líneas 40 y 41:
   ```javascript
   supabaseUrl: "https://TU-PROYECTO.supabase.co",
   supabaseAnonKey: "TU-CLAVE-ANON-AQUI"
   ```
5. Guarda el archivo.

---

### Paso 4: ¿Cómo ver las cotizaciones y bitácora?
Tienes **dos formas** de revisar la bitácora:
1. **Directo en Supabase**:
   - En el panel de Supabase ve a **Table Editor** > haz clic en la tabla `cotizaciones`.
   - Podrás ver cada cliente en tiempo real, filtrar, buscar, exportar a CSV y cambiar su estado a "Contactado" o "Cerrado".
2. **Desde tu sitio web (`bitacora.html`)**:
   - Abre `bitacora.html` en el navegador para ver un panel limpio con buscador rápido y botón de exportar a Excel/CSV.

## 🌐 PARTE 2: SUBIR A RENDER CON DOMINIO GRATIS

Render te da un dominio gratuito con HTTPS automático (ejemplo: `https://seguridad-salt.onrender.com`).

### Opción Recomendada: Despliegue como "Static Site" (Gratis y Ultra Rápido)
Los sitios estáticos en Render son **100% gratuitos**, están en una red CDN mundial y **nunca se duermen** ni se apagan por inactividad.

#### Paso 1: Subir tu código a GitHub
1. Crea un repositorio nuevo en tu cuenta de GitHub (ejemplo: `seguridad-salt`, público o privado).
2. Abre la consola en la carpeta del proyecto y ejecuta:
   ```bash
   git init
   git add .
   git commit -m "Sitio web Seguridad SALT con bitacora Supabase"
   git branch -M main
   git remote add origin https://github.com/TU-USUARIO/seguridad-salt.git
   git push -u origin main
   ```

#### Paso 2: Conectar y Desplegar en Render
1. Entra a [https://dashboard.render.com/](https://dashboard.render.com/) (inicia sesión con GitHub).
2. Haz clic en el botón azul **"New +"** (arriba a la derecha) y selecciona **"Static Site"**.
3. Selecciona tu repositorio de GitHub `seguridad-salt`.
4. Configura los campos:
   - **Name**: `seguridad-salt` (este será tu subdominio: `seguridad-salt.onrender.com`)
   - **Branch**: `main`
   - **Build Command**: Dejar vacío o poner `#`
   - **Publish Directory**: `.` (un punto, significa la raíz del proyecto)
5. Haz clic en **"Create Static Site"**.

¡Listo! En menos de 30 segundos Render construirá el sitio y te entregará tu enlace activo con candado SSL:
🔗 **`https://seguridad-salt.onrender.com`**

*(Nota: Si en el futuro compras un dominio propio como `www.seguridadsalt.com`, en esa misma pantalla de Render puedes agregarlo gratis en la sección "Custom Domains").*
